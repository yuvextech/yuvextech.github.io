# yuvexTech Website

Modern business website built with HTML and CSS.

## Features

- Responsive design
- Modern UI/UX
- Contact form
- Services showcase

## Getting Started

1. Clone the repository
2. Open `index.html` in your browser

## Deployment

This site is configured for GitHub Pages. Simply push to the main branch and the site will be live at `https://yuvextech.github.io`.

## Tech Stack

- HTML5
- CSS3
- No frameworks required
